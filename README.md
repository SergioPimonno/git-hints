# git-hints

## Небольшой гит-репозиторий для самостоятельной работы

`git clone https://github.com/PraktikumJava/git-hints.git`

## Хэш - главный указатель на коммит, уникальный внутри одного репозитория

`git status`выдает следующую информацию по коммиту: хэш, автор коммита, дата и список файлов со статусом unstaged/modified

###Посмотреть лог коммитов можно командой 
`git log` or `git log --oneline`
 oneline выдает сокращенную информацию о коммите, сокращенный хэш и 72 символа сообщения коммита

## HEAD - файл-ссылка на последний коммит, можно использовать как указатель.
